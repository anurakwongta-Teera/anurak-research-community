## Method and limits

ResearchGate was used for discovery: https://www.researchgate.net/profile/Anurak-Wongta . Search-index snapshots reported 44 records while an older opened snapshot reported 35. These counts are not unique published-article counts. The accessible records were compared against the existing ORCID import and a Crossref author query (1,000 results requested). Each of the 42 exact-name candidates was fetched again independently by DOI. Forty were journal-article records with Anurak Wongta in the author list; two were posted-content preprints. DOI values were normalized to lowercase; normalized titles were also checked for duplicates. All 26 existing DOIs remain represented. No abstracts or outcome claims were imported.

Verification uses publisher-deposited Crossref metadata, not independent editorial review of the papers. Some MDPI HTML pages returned HTTP 429; those were verified via their DOI metadata. Online/issue dates can differ; retain the existing explicit issue-date note for the Sensors and Actuators B article. Missing pagination is not invented.
